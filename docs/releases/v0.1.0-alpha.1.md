# v0.1.0-alpha.1

This is the first reviewed Migration Doctor pre-release. It is an unofficial developer tool, not an
OpenAI product.

## Highlights

- JavaScript, TypeScript, and Python analysis through one deterministic report contract.
- Tier A preview and temporary-copy verification for the locked transcription-model migration.
- Tier C Assistants inventory with explicit streaming and tool facets and no automatic rewrite.
- Opt-in repository commands with candidate-patch preservation checks.
- Hash-bound official sources, exact public-repository ground truth, and loopback SDK evidence.

## Install

Build the tagged source with the checked-in pnpm and uv locks, or pin the composite Action to the
reviewed 40-character commit published in the README. Do not pin the Action to this moving tag.
Workspace packages are private and are not available from npm or PyPI.

## Evidence boundary

The full deterministic suite, SARIF schema validation, synthetic benchmark, official-source drift
check, pinned public-repository evaluation, and official SDK loopback matrix are release gates. The
SDK harness verifies exact multipart request bytes without contacting the OpenAI API. Public
precision and recall apply only to the three pinned and manually reviewed repository revisions.

## Known limitations

Assistants transformations, live API parity, automatic test discovery, persistent caches, and a
production Codex route are not included. `verify-repository` executes trusted commands without host
filesystem or network isolation and is unavailable on Windows.
